# Documents Repository Audit (3.0)

Every file in the `Documents` repository (commit `782bd92`) was compared with the application, its knowledge-base
generators (`build/scripts/knowledge/*.py`) and its documentation. The 1,545 JSON files of
`ModernWork_SecurePlus_Baselines/PolicyRepository` are counted as one source: they are the control catalog.

## 3.1 update

The customer-variable placeholders in the Policy Repository bodies (`<RING>`, `<AdministratorGroup>`, `<EmergencyAccessAccountsGroup>`, `<ExclusionTempGroup>`, `<ExclusionPermGroup>`, `<SynchronizationServiceAccountsGroup>`, `<AADP2Group>`, `<FactoryResetProtectionAccount>`, `<TermsOfUseId>`, `<GsaSecurityProfileId>`, `<DialerAppUrlScheme>`, `%OrganizationId%`) are now filled from each customer's Deployment Variables, and folders are merged into source policies as the repository README describes.
