**Secure Plus – Modern Work 3.1.** Approved changes can now be applied to the customer tenant, behind a confirmation prompt and the Advanced Mode passcode. Published as a pre-release because the build is not code-signed.

### Downloads
- `GDS-SecurePlusAgent-3.1.0-win-x64-Setup.exe` – installer (recommended). Upgrades 3.0; no schema change.
- `...-portable.zip`, `...-framework-dependent.zip` – engineering builds.
- `...-SHA256SUMS.txt` – SHA-256 checksums.

### Apply to Tenant
- **Deployment > Change Execution > Apply to Tenant…** creates the approved change request's policies in the connected tenant through Microsoft Graph.
- Every apply shows a red confirmation listing the customer, tenant and changes, and needs the **Advanced Mode passcode**. A wrong passcode changes nothing.
- **Conditional Access** policies are created in **report-only** state. **Intune and endpoint security** policies are created as defined and **unassigned**: assign them to your pilot ring when ready. App protection targeted apps are set afterwards.
- Controls already passing are skipped, and so are policies whose name already exists in the tenant. Nothing is updated or deleted.
- Every created policy (and every failure) is written to the audit log, and the tenant is re-assessed when anything was created.

### Source Policies and Variables
- Controls from one Policy Repository folder are merged into one source policy (settings combined and renumbered), named `<RING>-<folder>`.
- **Deployment Variables** (expander on Change Execution, saved per customer): ring, administrator, emergency-access, exclusion and sync-account groups, factory-reset account, terms-of-use and Global Secure Access IDs, and a policy name prefix (e.g. `GDS - `). Groups can be entered by name; they are looked up in the tenant.
- A policy with a variable still unset is listed as manual and not created. Simulate shows the merged, filled policies in the package first.

### Before You Apply
- The app registration now requests write permissions: `Policy.ReadWrite.ConditionalAccess`, `DeviceManagementConfiguration.ReadWrite.All`, `DeviceManagementApps.ReadWrite.All`, `DeviceManagementServiceConfig.ReadWrite.All`. **Tenants registered before 3.1 must update their app registration and grant admin consent again** (Workspace > Tenant App Registration). Without it, Graph returns 403 and the step explains what to do.
- Set the customer's Deployment Variables and run **Simulate** to review the package.

### Known Issues
- The app does not use AI services.
- Group Policy (GPO) deployment is not included; Graph policies only.
- Experience scores, framework notes, SOW templates and scoring weights remain GDS drafts. Unsigned build: SmartScreen may warn.
