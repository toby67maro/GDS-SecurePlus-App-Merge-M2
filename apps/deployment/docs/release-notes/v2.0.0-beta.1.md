**Pre-release for testing.** First of the 2.0 milestones: data, seed, persistence, scheduler, Live Assessment, Dashboard and Reporting. Deployment, Workspace and Settings pages, Database Health and the full UI sweep follow in 2.0.0. Pages not finished in this pre-release show "Not yet available" (listed under Known Issues).

### Downloads
- `GDS-SecurePlusAgent-2.0.0-beta.1-win-x64-Setup.exe` – installer (recommended). Self-contained; run as an administrator. Upgrades an existing installation; your data in `%LOCALAPPDATA%\Global Data Systems\Secure Plus Agent` is kept.
- `...-portable.zip`, `...-framework-dependent.zip` – engineering builds.
- `...-SHA256SUMS.txt` – SHA-256 checksums of every download.

### Main Interface
- Menu sections start collapsed at launch (sections pinned open stay open).
- Deployment icon is a vector rocket taking off, tilted about 60° from horizontal, in the GDS accent colour.
- One search box everywhere it is used so far: magnifying glass, placeholder, clear (×), 250 ms debounce.
- Pages with their own Customer drop-down follow the customer selected at the top until you pick another.

### Dashboard
- **Roadmap** (fixed): remediation roadmap in four phases by priority, severity, effort and policy-set dependencies, with status and empty state.
- **Heat Map** (new): rows × columns from Framework, Compliance Standard, Experience, Solution Area, Policy Set, Severity, Risk Level, Effort, Status or Control Type; colour by compliance % or failing count; add/remove filters; date range; legend, tooltips, drill-down.
- **Catalog**: every filter starts on (All) including Result; Framework multi-select; search box; collapsible Control Details (Overview, Microsoft Graph Request with Copy, Remediation Options, Implementation Details).
- **Fleet View** (new): every tenant with latest assessment, compliance, failing controls by severity, trend, schedule status and quick actions.

### Assessments
- **Recurring Assessment**: Frequency first (Hourly, Daily, Weekly, Monthly) with frequency-specific fields, inline validation, live Next Run preview and time zone. Schedules list: Customer, Name, Frequency, Days, Month, Next Run, Last Run, Status (Running/Succeeded/Failed), State switch, Edit / Run Now / Delete, filters and search.
- Schedules also run while the application is closed: a background runner is registered in Windows Task Scheduler for your account (every 5 minutes while you are signed in).
- Assessments list shows the current customer; Include Other Customers adds or removes others; the Sample column is gone.
- **Live Assessment**: run list of up to 25 tenants, per-tenant status and Assess Tenant Now, Run Live Assessments Now with Max Concurrent Assessments (default 5, max 20) and Cancel.

### Reporting
- New **Control, Solution, Specification, Compliance, Framework and Experience Completion Views**: customer drop-down, scope and filters, KPIs, chart, drill-down and export to .csv, .html (GDS branded), .json and .txt.
- **Specification Comparison** replaces Golden Tenant Comparison: target tenant versus any specification and/or other tenants.

### Database
- Schema V0006 (SQL Server and SQLite): seed versions, control details, schedules v2 and run history, specifications, baselines, change requests, exceptions and edit audit.
- Seed data shipped in the installer and imported at setup with progress: 3,238 controls (68 identical duplicates merged with aliases; `CA-203-2` kept as a variant), 11 policy sets, 3 standard specifications, 3 baselines, solution and experience areas, remediation content and implementation details (generated content is marked "Generated – needs validation"). Versioned and idempotent; never overwrites customer data.
- Every assessment (manual, scheduled, live) is stored in chunks; a run that stops part-way is kept as Partial.

### Known Issues
- Not yet available in this pre-release: Change Request, Change Execution, Tracker, Customer Profiles, Specification Profiles, Exceptions, Workspace Configuration, Database Health. Baseline Configurations still shows the earlier Golden Tenant configuration page.
- Logos: no GDS logo files were supplied; the header uses the text wordmark.
- Unsigned build: SmartScreen may warn (More info > Run anyway).
