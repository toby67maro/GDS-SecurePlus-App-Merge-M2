**Secure Plus – Modern Work 2.0.0.** Complete 2.0 release: versioned reference data in the installer, persisted assessments, recurring and live assessments, Dashboard and Reporting, the Deployment workflow, Workspace and Settings pages and SQL Server health monitoring. Published as a pre-release because the build is not code-signed.

### Downloads
- `GDS-SecurePlusAgent-2.0.0-win-x64-Setup.exe` – installer (recommended). Self-contained; run as an administrator. Upgrades 1.x and 2.0.0-beta.1; your data in `%LOCALAPPDATA%\Global Data Systems\Secure Plus Agent` is kept.
- `...-portable.zip`, `...-framework-dependent.zip` – engineering builds.
- `...-SHA256SUMS.txt` – SHA-256 checksums of every download.

### Main Interface
- Menu sections start collapsed at launch (pinned sections stay open). Every menu entry opens a working page; placeholder pages are gone.
- GDS header wordmark (monogram badge in the accent colour); theme colours drive status chips and charts.
- `docs/UI_STYLE_GUIDE.md`: Title Case for labels, headings, buttons and columns; sentence case for help text. Applied across every page ("Roadmap", "Dashboard").
- One search box everywhere (magnifying glass, placeholder, clear, 250 ms debounce). Page customer drop-downs follow the global customer until changed.

### Dashboard
- **Roadmap** fixed: customer drop-down, four phases by priority, severity, effort and dependencies, empty state.
- **Heat Map** (new) with selectable rows and columns, colour by compliance % or failing count, legend, drill-down.
- **Catalog**: filters default to (All) including Result; Framework multi-select; search; duplicate IDs resolved at the source with a unique constraint; collapsible Control Details (Overview, Microsoft Graph Request with Copy, Remediation Options tabs with Copy, Implementation Details); generated content marked.
- **Fleet View** (new): every tenant with latest compliance, failing controls by severity, trend and schedule status.

### Assessments
- **Recurring Assessment**: frequency first (Hourly, Daily, Weekly, Monthly), validation, Next Run preview, time zone; schedules list with Customer, Name, Frequency, Days, Month, Next Run, Last Run, Status and State; Edit, Run Now, Delete; runs in the background through Windows Task Scheduler even when the app is closed.
- Assessments list starts on the current customer; Include Other Customers adds or removes others; Sample column removed.
- **Live Assessment**: run list of up to 25 tenants, per-tenant status, Run Live Assessments Now with Max Concurrent (default 5, limit 20), Cancel; results stored.

### Deployment
- Rocket icon tilted about 60° in the accent colour.
- **Change Request**: Draft → Submitted → Approved/Rejected → Scheduled → Completed, risk, window, rollback plan, controls in scope, full audit trail.
- **Change Execution**: pre-checks, step plan, progress and log, deployment package (Deploy.ps1 and Microsoft Graph bodies; Conditional Access in report-only state), Record As Applied re-assesses the tenant and completes the request. The application does not write to tenants in this release (see Known Issues).
- **Tracker**: every change request with status, dates and outcome.

### Reporting
- Control, Solution, Specification, Compliance, Framework and Experience Completion Views with customer drop-down, filters, KPIs, chart, grid and export to .csv, .html (GDS branded), .json and .txt.
- **Specification Comparison** replaces Golden Tenant Comparison.

### Workspace
- Customer Profile Import/Export page removed. **Customer Profiles**: search, inline edit with validation, audit, export one or all (secrets are never exported).
- **Specification Profiles**: guided builder, clone, assign and unassign, delete blocked while assigned.
- **Exceptions**: approved, time-limited exceptions count as satisfied in every report.
- One shared export service for every page.

### Settings
- **Workspace Configuration** replaces the import/export page: view and edit every non-secret setting with its source, JSON export, and JSON import with validation and a change preview.
- **Baseline Configurations** replaces Golden Tenant Configuration: build, clone, edit, delete (with confirmation), activate/deactivate; configure frameworks, standards, experiences, policy sets, controls and policies; the bottom panel shows each customer's compliance with the selected baselines, updated as the selection changes.

### Database
- Schema V0006 (SQL Server, Azure SQL and SQLite). Installer ships the full seed; setup connects or creates, migrates and imports it idempotently with progress and a log; a seed-version table records each dataset; customer data is never overwritten; the build validates seed counts.
- Seed: 3,238 controls (68 identical duplicates merged with aliases; `CA-203-2` kept as a variant), 2,500 expected settings, 11 policy sets (514 members), 8 frameworks with 87 requirements (17,393 mappings), 1,452 standard items, 3 specifications, 3 baselines, 18 reference values, 3,238 control details.
- Every assessment is stored in chunks; failed and partial runs are kept and marked; reports read the stored results.
- **Database Health** (new): files and disk space (warning below 15 % free, critical below 5 %), CPU, memory, sessions, blocking, top waits, growth trend, last backup, version and edition; refreshes every 45 seconds while visible; degrades gracefully without VIEW SERVER STATE and offers a grant script; "Last updated" time.

### Known Issues
- **No writes to customer tenants.** Change Execution produces a deployment package and records the change after it is applied; creating Conditional Access policies directly from the app awaits the owner's go-ahead.
- Generated remediation and implementation content is marked "Generated – needs validation" and should be reviewed before use.
- No GDS logo files were supplied: the header uses the text wordmark.
- Unsigned build: SmartScreen may warn (More info > Run anyway).
- Scheduled assessments run only while the Windows user is signed in.
