**Secure Plus – Modern Work 4.0.0-beta.2.** A test build: install it on test computers against a test SQL Server.

### Upgrade
Installs over 4.0.0-beta.1 and upgrades the database to V0012 (V0010 catalogue licensing column, V0011 tenant inventory, V0012 Lead edits).
A 3.x database is still not supported: start from a fresh database as for beta.1.

Existing tenants keep working with their client secret. Open **Customer Profiles > Tenant Access > Update Read Access** once per tenant
(a Global Administrator signs in): the app is renamed *GDS Secure Plus Read*, gets Exchange and Purview read access and the Global Reader
role, switches to a certificate, and loses its write permissions and client secrets. Then use **Enable Deployment Access** only for a deploy phase.

### Added
- **Connect tenant** when creating a customer: automatic registration, then a **quick scan** of users, groups, membership, roles, licences,
  domains and a posture snapshot. *Skip – connect later* is available.
- **Quick scan** and **in-depth scan** on *Assessment Scan* (renamed from Assessment Engine) and in schedules; Live Assessment runs quick scans.
  In-depth scans add Intune devices, policy and app assignments, sign-in activity, MFA methods, licences per user, tenant settings and the
  read-only PowerShell collector.
- **Tenant Users and Groups** on Customer Profiles (search, export) and **Entra group pickers** for user groups and group deployment variables.
- **Settings > Policies and Policy Sets** for Leads: create, edit, hide, delete and revert policies and policy sets. Edits survive catalogue
  reloads and upgrades; *Update available* and *Retired* are flagged.
- **195 tenant settings** across Entra ID, Conditional Access, Intune, Defender XDR, Exchange Online and Defender for Office 365,
  SharePoint/OneDrive, Teams, Purview, Copilot and AI, Power Platform, Microsoft 365 admin center, Global Secure Access, Windows 365/AVD,
  hybrid identity and Azure: 131 assessed automatically, 64 manual checks with click paths. Settings that need a licence the tenant lacks
  show *Info: not applicable* and are not scored.
- **Read-only PowerShell** for Exchange Online, Security & Compliance and Teams (in-depth scans): PowerShell 7 with ExchangeOnlineManagement
  3.10.1 and MicrosoftTeams 8.0.0. Tick *Install PowerShell modules* in the installer, or run `prerequisites\Install-SecurePlusPowerShellModules.ps1`.
- **Separate Read and Deploy registrations** with **certificate** credentials (private key only in the encrypted secret store).
- *MFA method* option **Shared device: QR code + PIN** for frontline shared devices: single-factor, not MFA; always paired with CA-213/CA-214 and
  limited to the frontline group.

### Changed
- Every Conditional Access policy excludes the break-glass group and is deployed report-only, monitored at least 14 days (21 recommended).
- Catalogue rebuilt (3,333 controls): CA-213/CA-214 added, CA-200 renamed, Internet Explorer settings and duplicates removed, tenant settings added.
- Licensing column removed from the catalogue table; NAICS no longer loaded.
- Reports use the latest in-depth scan (quick scans only when there is none).
- Change Execution needs deployment access; it explains how to enable it.

### Database
- **V0010**, **V0011**, **V0012** (upgrade from beta.1).

### Not in this build
- Step-up MFA replacing the passcode, Entra sign-in and roles in the app (4.0.0-beta.3).
- Workspaces as tenants (4.0.0-beta.4); drift and Quick View (4.1); experience mapping (4.2, proposal first).
- Automatic Azure assessment (5.0 with Azure Lighthouse); PowerShell deployment of Exchange, Purview and Teams settings (4.5).
