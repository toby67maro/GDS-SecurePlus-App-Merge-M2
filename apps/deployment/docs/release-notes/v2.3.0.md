**Secure Plus – Modern Work 2.3.0.** Knowledge base phase 2: CIS Benchmarks, Microsoft security baselines, the Secure Plus work breakdown structure, the question bank and the deployment method matrix are loaded into the SecurePlus database. Published as a pre-release because the build is not code-signed.

### Downloads
- `GDS-SecurePlusAgent-2.3.0-win-x64-Setup.exe` – installer (recommended). Upgrades 2.x; no schema change.
- `...-portable.zip`, `...-framework-dependent.zip` – engineering builds.
- `...-SHA256SUMS.txt` – SHA-256 checksums of every download.

### After Upgrading
Phase 2 loads in the background the first time 2.3 connects (activity panel: **Load the knowledge base**); phase 1 is already loaded and is not reloaded. **Settings > Database Health > Data Coverage** shows both versions; **Reload Knowledge Base** reloads both (on SQL Server allow up to about 10 minutes).

### Database
- **Baselines** (`cfg.*`): 56 CIS Benchmarks (Windows, Windows Server, Intune, macOS, iOS/iPadOS, Android, Edge, Chrome, Microsoft 365, Azure, AWS, GCP, Google Workspace, SQL Server, VMware ESXi, Defender Antivirus, Power Platform, MCP Server) and the Microsoft security baselines for Windows 11 26H2, Windows Server 2025 v2602 and Microsoft 365 Apps 2512: 10,507 recommendations with profiles, sections, recommended values and 22 GPO packages.
- **Technical settings**: 8,695 settings (registry, Group Policy, Intune Settings Catalog) with 21,431 alternative identifiers. A setting is shared by every baseline that configures it, so CIS and Microsoft values can be compared (185 settings are configured by both).
- **Framework links**: 7,966 CIS recommendation links to CIS Controls v8.1 safeguards, 1,290 to NIST SP 800-53 and 1,132 to NIST CSF 2.0, and 843 DISA STIG references; recommendations therefore reach SCF controls, risks, threats and ATT&CK through the phase 1 crosswalk.
- **Delivery** (`dlv.*`): phases P0–P4, 29 workstreams and the 193-task Secure Plus WBS (hours, duration, deliverables, dependencies), each task linked to the GDS standard items it delivers.
- **Questions** (`eux.*`): 474 Secure Plus discovery decisions (why asked, configuration impact, owner, default) linked to the standard items they configure, and the EaaS discovery and design-workshop forms (139 questions, 477 answers, 80 rules, 12 personas).
- **Deployment method matrix** (`deploy.*`, `kb.Product`): 115 Microsoft 365 / Azure setting groups with deployment method, app-only support, read/write, portal-only gaps and drift option.
- **Sources** (`src.*`): every source file with version, SHA-256 and licence. CIS text is stored for internal use only.

### CIS CSV Files
The CIS CSV files produced with Copilot were used after checking them against the PDFs: 5 recommendation numbers and 1,468 registry paths were corrected (details in `docs/knowledge-base/CIS_CSV_EVALUATION.md`).
