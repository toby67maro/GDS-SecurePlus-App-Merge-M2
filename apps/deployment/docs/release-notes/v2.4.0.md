**Secure Plus – Modern Work 2.4.0.** Knowledge base phase 3 and assessment results in the EaaS tables. Published as a pre-release because the build is not code-signed.

### Downloads
- `GDS-SecurePlusAgent-2.4.0-win-x64-Setup.exe` – installer (recommended). Upgrades 2.x; no schema change.
- `...-portable.zip`, `...-framework-dependent.zip` – engineering builds.
- `...-SHA256SUMS.txt` – SHA-256 checksums of every download.

### After Upgrading
Phase 3 loads in the background the first time 2.4 connects (activity panel: **Load the knowledge base**); phases 1 and 2 are already loaded and are not reloaded. **Settings > Database Health > Data Coverage** shows all three versions.

### Database
- **Licensing**: every Microsoft licence SKU (619) and the service plans each includes (from Microsoft's licensing service plan reference); service plans, CTID security capabilities and admin-centre solutions as capabilities (1,224).
- **Threat coverage** (MITRE CTID): which ATT&CK techniques each Microsoft 365 and Azure capability protects, detects or responds to (1,630), and NIST SP 800-53 and CIS Controls 8.1 mitigations (6,387).
- **Service tiers**: the features of Essentials, Secure Plus and Secure Plus Premium from the Service Tiers deck, their base licences and the capabilities those include.
- **Customer Deployment Checklist v2.0** as a GDS standard (371 items) with tier inclusion and guidance.
- **Configuration changes**: the 1,786 deployable catalog policies with the framework requirements they support (10,663 links), 1,459 known issues (side effects) and 3,238 guidance entries (benefits, user impact, steps, validation, rollback; draft until reviewed).
- **Baselines**: Windows 11 25H2 → 26H2, Windows Server 2025 and Microsoft 365 Apps setting changes; 21,754 relations between baseline recommendations that configure the same setting (same or different value); 12,515 audit and remediation procedures.
- **Experience and delivery**: 30 experience expectations with the policies that support or contradict them; rollout rings (pilot, UAT, production); 189 WBS complexity factors.
- **Framework attributes**: CIS Controls v8.1 implementation groups, asset class and security function; CMMC SPRS points, POA&M eligibility and NIST 800-171 references; ITAR USML, CUI, FCI, PCI CDE and ePHI scope categories; status labels of the compliance worksheets; Microsoft products suggested per CMMC requirement.
- **Scoring**: NIST SP 800-30 scale, the GDS default risk model (likelihood × impact), derivation rules and source precedence, 28,664 enrichment values with source and confidence, and a risk score and priority for each of the 1,591 SCF controls.

### Assessments
- After each completed assessment, Secure Plus also writes the EaaS view: open findings (`cust.Finding`), a status per framework requirement derived from the mapped checks (`cust.RequirementResult`), a score snapshot and an observation snapshot (`audit.Snapshot`).

### Known Issues
- Scoring weights, checklist tier inclusion and guidance are drafts for GDS review (see `docs/DECISIONS.md`).
- The rate card workbook is encrypted, so packages, components, add-ons, roles and rates are not loaded. SOW, estimates, project plans, specifications, drift comparison, ConnectWise sync and Forms tables belong to features not built yet.
- No writes to customer tenants. Unsigned build: SmartScreen may warn.
