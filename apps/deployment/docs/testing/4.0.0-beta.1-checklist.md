# 4.0.0-beta.1 test checklist

Fresh database: remove the 3.x test database first.

1. **Install**: Server/All-in-one creates the database at V0009 and loads the catalogue; a Workstation connects.
2. **Dashboard**: hover over every tile; no error appears.
3. **Customer Profiles > Integration / Workspace Settings**: edit, save, reopen; values kept; managed keys read-only.
4. **Top bar**: customer, workspace and tenant icons open pickers (Esc closes); the selected customer · tenant and workspace are shown.
5. **Change request templates**: GDS default cannot be edited or deleted; assign to a customer, edit (version increases), Save as Global, preview the approval email.
6. **Industry**: pick an industry on a new customer and in Customer Profiles (Other asks for text); a Lead edits the list; Fleet View column and filter.
7. **Experience**: new profile names; Remote Site classification; Network Access (GSA) questions; new frameworks; Essential Eight shown only where already selected.
8. **Project Plan**:
   - Edit Start/Finish inline; Up/Down changes order only; Insert above/below (neighbour's start, 1 day, no dependencies).
   - Open the detail pane; pop it out, move/resize, close and reopen (position remembered); disconnect the monitor → docks with a message.
   - Mark as done without a note is refused; with a note and attachment it shows "Manual – attested" in history.
   - Remediate: refused without an approved linked change request; with one, the confirmation shows before/after, rollback and asks for the passcode; the task becomes Staged (CA report-only, Intune unassigned).
   - A Staged task cannot be completed until its linked controls pass after re-assessment.
   - History cannot be edited (SQL: UPDATE/DELETE denied).
9. **Regression**: full automated suite on SQL Server 2022; smoke test of each menu.
