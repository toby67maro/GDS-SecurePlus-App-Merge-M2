# 3.2.0-beta.1 Test Checklist (shared SQL Server and installer)

Every item must pass before beta.2 starts. Record the result, tester and date.

| # | Test | Expected | Result |
|---|---|---|---|
| 1 | **Server install** on a clean computer: Server, SQL Server name, database `SecurePlus` | Connection test passes; database created; schema version 8; reference catalog loaded; running setup again changes nothing | |
| 2 | **Workstation install**: type the server; then a silent install with `/TYPE=Workstation /SERVER=...` | Server pre-filled in Database Configuration; the install type shown there; nothing created or upgraded by the workstation | |
| 3 | **Version check**: a 3.1 workstation against the 3.2 database; a 3.2 workstation against a 3.1 database | 3.1: *Update required*; 3.2: asks for the Server install to be upgraded first | |
| 4 | **Users & Roles**: add yourself as Lead first; add an Engineer and a Sales user; Grant Database Access (or run the SQL script) | First user must be a Lead; only Leads change users; last Lead cannot be removed; logins and `secureplus_*` roles created | |
| 5 | **Database permissions** (signed in as each user) | Sales cannot read tenant credentials (assessments fail with a clear message); Engineer can; nobody can UPDATE or DELETE `secureplus.AuditLedger` | |
| 6 | **Audit ledger**: run an assessment and an Apply to Tenant on a test tenant | Ledger has `CredentialUse` and `Deployment` rows with user and computer | |
| 7 | **Organization key**: a Sales user tries to enter the key | Refused: only Engineer, Technician/Deployer and Lead hold the key | |
| 8 | **Scheduling computer**: set PC-A; create a schedule due in 5 minutes; keep the app open on PC-A and PC-B | Only PC-A runs it; heartbeat shown in Database Health; stop PC-A for 15+ minutes → warning | |
| 9 | **Failure cases**: scheduling PC off; SQL Server unreachable; VPN dropped | Clear messages; no data loss; schedules resume when PC-A returns | |
| 10 | **Move to SQL Server**: a 3.1 SQLite database → empty SQL Server database | Every table's count matches; SQLite file unchanged and backed up; app works after switching | |
| 11 | **3.1 regression**: smoke test of every menu, assessment, Apply to Tenant (test tenant), reports and exports | As in 3.1 | |
| 12 | **Automated**: full test suite including SQL Server 2022 tests in CI | All pass | |
